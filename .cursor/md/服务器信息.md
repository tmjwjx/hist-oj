## 注意事项

1. **判题机部署**: 所有判题服务都部署在远程服务器上，主服务器不运行判题服务
2. **测试用例同步**: 通过 rsync 从主服务器同步到各判题机
3. **服务注册**: 判题机通过 Nacos 自动注册，ephemeral 实例会在心跳超时后自动注销
4. **数据库清理**: judge_server 表中只保留当前运行的判题机记录

## 维护命令

### 查看 Nacos 注册的判题服务
```bash
TOKEN=$(curl -s -X POST 'http://43.143.133.62:8848/nacos/v1/auth/login' \
  -d 'username=root&password=hist2025' | grep -o '"accessToken":"[^"]*"' | cut -d'"' -f4)
curl -s "http://43.143.133.62:8848/nacos/v1/ns/instance/list?serviceName=hoj-judgeserver&accessToken=$TOKEN"
```

### 从 Nacos 注销判题机
```bash
TOKEN=$(curl -s -X POST 'http://43.143.133.62:8848/nacos/v1/auth/login' \
  -d 'username=root&password=hist2025' | grep -o '"accessToken":"[^"]*"' | cut -d'"' -f4)
curl -X DELETE "http://43.143.133.62:8848/nacos/v1/ns/instance?serviceName=hoj-judgeserver&ip=<IP>&port=8088&accessToken=$TOKEN"
```

### 手动同步测试用例（在判题机上执行）
```bash
docker exec -e RSYNC_PASSWORD=hist2025 hoj-rsync-slave \
  rsync -avz rsync://hojrsync@43.143.133.62:873/testcase/<problem_id>/ \
  /hoj/testcase/<problem_id>/
```

### 查看最近判题记录
```bash
docker exec hoj-mysql mysql -uroot -phist2025 -e \
  "USE hoj; SELECT submit_id, pid, username, status, judger, submit_time \
   FROM judge ORDER BY submit_time DESC LIMIT 10;"
```
