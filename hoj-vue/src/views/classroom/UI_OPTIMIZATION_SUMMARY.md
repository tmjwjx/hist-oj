## 通用优化点

### 1. 颜色系统
```css
主色: #4A90E2
浅蓝: #5BA3F5
极浅蓝: #E3F2FD
次色: #64B5F6
背景色: #F5F9FC
```

### 2. 按钮规范
- 所有按钮都包含图标 + 文字
- 使用统一的圆角（8px）
- 内边距统一（10px 20px）
- 悬停效果：阴影加深 + 向上移动1px
- 类型：primary（主色）、secondary（次色）、success（成功）、warning（警告）、danger（危险）

### 3. 卡片设计
- 统一圆角：12px
- 阴影：`0 2px 8px rgba(74, 144, 226, 0.08)`
- 悬停阴影：`0 8px 24px rgba(74, 144, 226, 0.15)`
- 顶部渐变背景
- 边框：`1px solid var(--classroom-border)`

### 4. 交互动画
- 卡片悬停：`transform: translateY(-4px)`
- 按钮悬停：`transform: translateY(-1px)`
- 淡入动画：`classroom-fade-in`
- 箭头滑动：`translateX(4px)`

### 5. 响应式设计
- 移动端（<768px）：
  - 网格布局变为单列
  - 按钮全宽显示
  - 间距自动调整
  - 时间线简化显示
