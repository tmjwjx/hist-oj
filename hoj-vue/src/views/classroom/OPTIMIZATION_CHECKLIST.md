## 📋 已知限制

1. **国际化**
   - 部分新增文字可能需要添加到i18n配置
   - 建议检查所有翻译键

2. **浏览器支持**
   - CSS Grid在IE11不支持
   - CSS变量在IE11不支持
   - 建议使用现代浏览器

3. **主题切换**
   - 当前只支持浅色主题
   - 深色模式需要额外开发
