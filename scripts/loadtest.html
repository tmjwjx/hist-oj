BingOJ 加载压测台（本地 → 线上）

每个会话使用独立随机 UUID，按到达窗口加入，独立轮询真实排位；先验证无票据页面门禁，再凭一次性票据请求页面、静态资源和首页接口，完成后释放槽位。从实际 app 脚本解析首页动态组件和 logo，加载首页使用的图标字体、排名头像与展开公告图片；每个会话独立保留身份和排位。每个会话最多并发 3 个资源请求；排队轮询与心跳立即交给浏览器发送，使用高优先级，不再共享测试脚本的全局发送队列。400 个会话仍是 400 个排队对象，服务端决定加载名额。幂等 GET 网络中断最多重试 2 次；成功可能包含重试恢复，失败请求仍累计。一次性票据不重试。
这是单个浏览器中的资源请求模拟，不执行 Vue，不是独立进程或独立浏览器；共享浏览器连接限制，HTTP/1.1 连接限制会影响测试器吞吐。不会执行 JavaScript 动态导入、CSS 条件判断和懒加载逻辑；真实浏览器无缓存测试需另行进行。请求使用 credentials: omit、cache: no-store；仅页面和资源加随机查询参数，首页 API 保持真实参数以保留相同的服务端缓存行为；服务端/CDN 是否缓存仍取决于其配置。流量为解压后响应体字节。

服务端快照：尚未收到。后端人数包含其他真实访客。

每个会话可单独退出，以观察后端排位和人数更新。停止后清理请求继续执行；新一轮使用全新身份。
