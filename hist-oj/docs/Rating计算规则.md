# Rating 计算规则

## 概述

本系统采用基于 Elo 算法的 Rating 计算机制，并针对校队内部使用场景进行了优化，增加了新手保护和参与激励机制。

---

## 基础参数

| 参数 | 值 | 说明 |
|-----|-----|------|
| 初始 Rating | 1500 | 新用户的起始分数 |
| K 值 | 32 | 波动系数，值越大单场波动越大 |
| Rating 下限 | 800 | 分数最低不会低于此值 |
| 最少参赛人数 | 3 | 少于 3 人的比赛不计算 Rating |

---

## 核心算法

### 1. 期望排名计算

根据选手当前 Rating 与所有参赛者的 Rating 对比，计算"期望排名"：

```
期望排名 = 1 + Σ P(输给对手i)
```

其中，输给某个对手的概率：

```
P = 1 / (1 + 10^((我的Rating - 对手Rating) / 400))
```

**示例**：
- 我 1500，对手 1500 → 输的概率 50%
- 我 1500，对手 1900 → 输的概率 91%
- 我 1500，对手 1100 → 输的概率 9%

### 2. Rating 变化计算

```
Rating变化 = K × (实际得分 - 期望得分) / 参赛人数
```

其中：
- 实际得分 = 参赛人数 - 实际排名 + 1
- 期望得分 = 参赛人数 - 期望排名 + 1

**核心思想**：表现超出预期则涨分，低于预期则掉分。

## 特殊规则

### 1. 新手保护

**规则**：前 3 场比赛，掉分减半

**目的**：避免新手刚参赛就大幅掉分，打击参与积极性

**示例**：

| 参赛次数 | 原本掉分 | 实际掉分 |
|---------|---------|---------|
| 第 1 场 | -20 | -10 |
| 第 2 场 | -30 | -15 |
| 第 3 场 | -20 | -10 |
| 第 4 场 | -20 | -20（保护结束）|

**注意**：涨分不受影响，正常计算。

### 2. 参与激励

**规则**：只要过题了（AC ≥ 1），额外 +5 分

**目的**：鼓励选手积极参赛，只要认真参与就有奖励

**示例**：

| 过题数 | 原本变化 | 激励分 | 最终变化 |
|-------|---------|-------|---------|
| 5 | +20 | +5 | +25 |
| 1 | -15 | +5 | -10 |
| 0 | -20 | 0 | -20 |

**注意**：0 题不获得激励分（防止挂机混子）。

### 3. Rating 下限

**规则**：Rating 最低为 800，不会更低

**目的**：保底机制，避免分数过低打击信心

---

## 计算流程

```
1. 获取比赛排名数据
       ↓
2. 获取所有参赛者当前 Rating
       ↓
3. 使用 Elo 算法计算原始 Rating 变化
       ↓
4. 应用新手保护（前3场掉分减半）
       ↓
5. 应用参与激励（过题了 +5）
       ↓
6. 应用 Rating 下限（≥800）
       ↓
7. 保存结果
```

**场景**：30 人比赛，某新手（第 2 场比赛，当前 Rating 1500）

| 排名 | 过题 | 原始变化 | 新手保护 | +激励 | 最终变化 | 新 Rating |

## 自动计算

- 定时任务每 5 分钟检查一次已结束的比赛
- 在 `contest_rating_status` 表中标记 `is_rated = 1` 的比赛会自动计算
- 计算完成后标记 `rating_calculated = 1`，不会重复计算

### 设置计分比赛

```sql
INSERT INTO contest_rating_status (contest_id, is_rated, rating_calculated)
VALUES (1001, 1, 0);
```

## 配置项

配置文件：`configs/config.yaml`

```yaml
rating:
  initial_rating: 1500  # 初始 Rating
  k_factor: 32          # K 值
  check_interval: 5     # 定时检查间隔（分钟）
```

代码常量：`internal/utils/calculator.go`

```go
const MinRating = 800  // Rating 下限
```

新手保护和参与激励：`internal/service/rating.go`

```go
// 新手保护：前 3 场
if contestCount < 3 && change < 0 {
    change = change / 2
}

// 参与激励：+5 分
if record.AC > 0 {
    change += 5
}
```
